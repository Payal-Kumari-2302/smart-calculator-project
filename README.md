# 🔢 Smart Calculator

A simple and responsive smart calculator built using HTML, CSS, and JavaScript.  
It performs basic arithmetic operations with a clean user interface.

## 🚀 Features
- Addition, Subtraction, Multiplication, Division
- Responsive Design
- User-Friendly Interface
- Fast Calculations

## 🛠️ Technologies Used
- HTML
- CSS
- JavaScript
